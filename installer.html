Installer ou mettre à jour

  1. Touche Copier l’adresse du plugin ci-dessus.
  2. Touche Ouvrir windy.com/plugins. Sur téléphone, il faut rester dans Chrome : si l’appli Windy s’ouvre à la place, tape windy.com/plugins dans la barre d’adresse de Chrome.
  3. Choisis Load plugin directly from URL et colle l’adresse.
  4. Touche Install untrusted plugin. C’est fait.

Pour une mise à jour, c’est la même procédure : reviens sur cette page, elle donne toujours la dernière version.

Icône sur l’écran d’accueil (une seule fois)

  1. Ouvre cette page de raccourci.
  2. Menu ⋮ de Chrome → Ajouter à l’écran d’accueil → Créer un raccourci, nomme-le « Routage ».

Le raccourci ouvre toujours la version installée : inutile de le refaire après une mise à jour.

Premier lancement

Importe la polaire de ton bateau dans la section ⛵ Polaires (fichier .pol, .csv ou .txt) et associe-lui sa catégorie. Les polaires et les favoris sont gardés sur chaque appareil.
